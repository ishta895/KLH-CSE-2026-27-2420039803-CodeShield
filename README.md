## Project Abstract
CodeShield is an AI-driven vulnerability remediation pipeline designed to improve software security through automation. It uses Generative AI and Large Language Models (LLMs) to detect security vulnerabilities, analyse their causes, and suggest or generate suitable fixes.

These fixes are automatically tested and validated through a DevSecOps-based CI/CD pipeline before deployment. By reducing manual effort and enabling faster vulnerability resolution, CodeShield helps developers build more secure and reliable software. The project demonstrates the use of Adaptive Software Engineering, Generative AI, automated testing, CI/CD, and DevSecOps in a practical software development environment.
